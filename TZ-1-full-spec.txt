1. Главная задача

Доработать текущий сайт Crystal Water, не создавать дизайн с нуля.

Главная задача — сохранить узнаваемость и визуальный стиль оригинального сайта Crystal Water, но сделать новую версию:

визуально более качественной;
полностью адаптивной;
корректной на iPhone/Android;
удобной для заказа;
технически чистой;
SEO-оптимизированной;
с правильными изображениями;
без медицинских обещаний, которые нельзя подтвердить.

Новая версия должна максимально опираться на оригинальный сайт Crystal Water, а не придумывать совершенно новый бренд.

Сохранить:

фирменную цветовую палитру;
оттенки синего;

стили кнопок;
общую атмосферу оригинального сайта.

Description:
Доставка питьевой воды 19 л в Броварах и Киеве. Вода для дома, офиса и бизнеса. Заказ и доставка Crystal Water.

Добавить:
canonical;
Open Graph;
favicon;
правильный language;
sitemap.xml;
robots.txt;
JSON-LD.

Canonical должен указывать на настоящий production-домен, а не GitHub Pages. Google прямо рекомендует задавать предпочтительный canonical URL.

7. Schema.org

Добавить JSON-LD:
LocalBusiness
Organization
Product
Service
BreadcrumbList
FAQPage

Но не добавлять в schema утверждения, которых нет на странице или которые нельзя доказать — Google отдельно предупреждает, что structured data должна соответствовать видимому содержимому.

8. Удалить медицинские обещания

Это критически важно.

С текущей версии убрать/переписать утверждения типа:
«восстанавливает организм на клеточном уровне»
«стимуляция иммунитета»
«навсегда устраняет проблемы со здоровьем»
«помогает худеть»
«идеальный кислотно-щелочной баланс для организма»

Они сейчас реально присутствуют в контенте сайта.

Заменить на нормальный коммерческий язык:
тщательно очищенная питьевая вода;
приятный вкус;
удобная доставка;
подходит для ежедневного употребления;
проходит многоступенчатую очистку и контроль качества.

Никаких медицинских обещаний без подтверждённых доказательств.

⚠️ ВНИМАНИЕ — ПРОТИВОРЕЧИЕ С ГЛАВНЫМ ПРИОРИТЕТОМ ПРОЕКТА:
Смена URL-структуры статей с текущей (плоские файлы вида
"43-chistaya-voda-izbavlennaya-ot-khlora.html" в корне) на новую
("/blog/obratnyj-osmos/") НАПРЯМУЮ ПРОТИВОРЕЧИТ основному требованию
проекта — сохранить все текущие URL для защиты SEO-позиций (см. начало
INSTRUCTIONS_FOR_NEXT_ASSISTANT.md). Если менять структуру статей —
ОБЯЗАТЕЛЬНО настроить 301-редиректы со старых URL на новые и уточнить
у пользователя, готов ли он на временную просадку трафика на период
переиндексации. Не делай этот переход молча.

Не создавать десятки автоматически сгенерированных страниц.

Контент должен быть полезным людям, а не написанным исключительно ради ключевых слов — это соответствует актуальной рекомендации Google по people-first content.

11. Изображения

Все изображения:
реальные;
качественные;
с правильными alt;
WebP/AVIF где возможно;
с width и height;
оптимизированные по размеру;
lazy-loading для изображений ниже первого экрана.

Не использовать огромные изображения, если они отображаются маленькими: Lighthouse отдельно рекомендует отдавать изображения в размере, соответствующем фактическому отображению.

13. Производительность

Цель:
LCP < 2.5 sec
INP < 200 ms
CLS < 0.1

Это ориентиры Google для хорошего Core Web Vitals.

настоящая локальная компания по доставке воды, а не SEO-шаблон.
