## 🟡 P1 — SEO, ДИЗАЙН, НОВЫЕ БЛОКИ

### 4. SEO-фундамент

**Профессиональный SEO-подход:**

- [ ] `<title>` — уникальный на каждой странице (50-60 chars)
- [ ] `<meta name="description">` — уникальный (140-160 chars)
- [ ] `<h1>` — один на страницу, с основным ключом
- [ ] H2-H3 иерархия заголовков
- [ ] Canonical URL на каждой странице
- [ ] `sitemap.xml` — все страницы
- [ ] `robots.txt` — корректный
- [ ] JSON-LD:
  - `LocalBusiness` (адрес, часы, телефон)
  - `FAQPage` (частые вопросы о воде, доставке)
  - `Article` (для статей/блога)
  - `Product` (для воды, кулеров)
- [ ] Semantic HTML5: `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`
- [ ] Alt text на всех изображениях (описательные, с ключами)
- [ ] `llms.txt` — для AI-краулеров

### 5. Дизайн — премиум вода

**Станция очистки и доставки — дизайн должен отражать чистоту:**

- [ ] **Цветовая схема:** доработать фирменные цвета
  - Синий тёмный `#0f5f96` — хедер/футер
  - Синий `#1e88c7` — кнопки/акценты
  - Бирюзовый `#00c2e6` — hover/выделение
  - Белый + светло-голубой — карточки/секции
- [ ] **Типографика:** читаемые шрифты, 16px+ для текста
- [ ] **Карточки услуг:** иконка + заголовок + цена + CTA
- [ ] **Схема очистки воды:** 8 этапов визуально (уже есть — улучшить)
- [ ] **Блок «Почему мы»:** 3-5 ключевых преимущества с иконками
- [ ] **Отзывы:** блок с каруселью/сеткой (пока заглушка — заполнить позже)
- [ ] **Футер:** карта проезда, соцсети, контакты, часы работы

### 6. Новые блоки (для улучшения конверсии)

- [ ] **Hero-секция:** видео/изображение воды + заголовок + CTA
- [ ] **How it works:** 3-4 шага (выбрал → позвонил → получил)
- [ ] **Таблица цен:** с фильтрацией (вода/кулеры/бутыли)
- [ ] **Форма заказа:** inline на главной + отдельная страница
- [ ] **FAQ:** аккордеон на каждой услугой
- [ ] **Блог/статьи:** полезные материалы (как выбрать воду, уход за кулером)
- [ ] **Галерея продукции:** фото с описанием

### 7. Адаптив (mobile-first)

**Проверить на breakpoints:**
- [ ] 320px (Samsung Galaxy Fold / SE)
- [ ] 375px (iPhone SE / 13 mini)
- [ ] 390px (iPhone 14 Pro)
- [ ] 430px (iPhone 16 Pro Max)
- [ ] 768px (iPad)
- [ ] 1024px (iPad Pro / landscape)
- [ ] 1440px (desktop)
- [ ] 1920px (wide)

**Проверить:**
- [ ] Нет горизонтального скролла
- [ ] Тач-зоны ≥ 44px
- [ ] Шрифт ≥ 16px (нет zoom)
- [ ] Меню: burger на mobile
