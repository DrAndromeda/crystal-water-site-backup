## ЭТАП 1: ПОЛНЫЙ АРХИВ

### Команда для зеркала с живого сайта
```bash
wget --mirror \
     --warc-file=crystalwater_complete \
     --page-requisites \
     --adjust-extension \
     --convert-links \
     --restrict-file-names=windows \
     --domains=crystalwater.kiev.ua \
     --wait=1 \
     "https://crystalwater.kiev.ua/"
```

### Команда для web.archive (если чего-то не хватает)
```bash
wget --mirror \
     --warc-file=crystalwater_archive \
     --page-requisites \
     --adjust-extension \
     --span-hosts \
     --domains=crystalwater.kiev.ua,web.archive.org \
     --wait=2 \
     "https://web.archive.org/web/2022/https://crystalwater.kiev.ua/"
```
